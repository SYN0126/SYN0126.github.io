# 余波

先说过程，我为什么来到了simit？首先是我怎么知道的simit，在考研那年6月我的室友和我说他考半所多么之容易（我的3位室友都是比我大一届的学长），给我发了一个考集院的学长上岸后写的经验贴加感言的pdf(下图)

我读了以后在某一节他写到：

![1](/images/Picture2.png)

后面又有提到：‘’

![1](/images/Picture3.png)

我看了以后把不知怎得把上高院和simit当成一个了，调剂还能选艾希设计，岂不美哉？于是这个搞错了名字的备选方案就在我心里埋下了种子。



现在回想，那天舍友告诉我这个pdf，是在暑假我要回家的前几天。如果当时回去没有和室友交流考研话题，而是疲劳一天回寝室默默的玩会手机然后休息，亦或者没聊到那位集院的学长，室友也没发我那个pdf，人生一定会走向不同的轨迹了吧？



我这样回溯遗落了一点，后面为什么跳车了。一开始在9月前，我的目标是北京大学，辅导班也报了。不过从5月开始我的学习状态一天不如一天，考研之前我摆了两年了，一切都回来了，都回来找我了。虽然我很向往北大，但是不够强烈，加上自控力，执行力差以及诸多的坏习惯。在9月14号，我把北大辅导班退掉了。毫无目的的过了几天把目标放在了微电子所和集成电路学院。后面又看群里说微电子所今年名额大减，于是为了稳上岸，在10月9日报考那天，我快速地做出了报考simit这个决策（按照学长的文档应该是上高院才对，太草了）所以也许在我那之前的性格，能力，经历来说，跳车也许是必然，只不过是往哪儿跳。但是跳车的必然也可以回溯，回溯到刚好不会跳车的节点。

先回溯一下我的室友：

我为什么和我的室友（告诉我那个pdf的）在一个寝室？是因为我大一下从材料物理专业转到了电子信息大类（第三志愿），第一志愿是计算机科学与技术，第二志愿是大数据科学与技术，第三个志愿我考虑过软件工程，但是学费太贵（家里条件不好，且根本不了解校园贷款政策）加上我对自己的应试实力过度自信，第三个就随便填了个电子信息（印象里电子也是不错的专业）。转专业成功后，由于宿舍不够给我安排到了和三个学长一个宿舍。这里就有两点，1.为什么没录上第一第二志愿？可以和上面的合并了：我又摆了，那时是22年 网课加回家，啥也没学，摆爽了，直接裸考的。2.为什么随便填个第三志愿选择了电子信息，这也许是我当时有限认识的较优解，现在看来，选择电气，软件工程，甚至没转成，留在材料物理也都问题不大。

 

现在回溯我摆的问题，22年摆都干什么？ 那就是打游戏，玩原神，lolm，lol,王者荣耀，或者刷抖音快手看点土的。为什么我打原神？是因为我一个很近的朋友打原神，我本来比他先知道原神，随便玩过一下，不怎么感冒就没玩了，后面因为和他一块玩二度入坑了。我很不想提及，但是这也是一个值得回溯的点，朋友的问题，后面再提。为什么玩英雄联盟以及lolm？是因为高中班级里面几个人在希沃白板搞了个lol的屏保。有一段时间晚自习没人动希沃白板，就会进屏保，里面的lol海报吸引了我（尤其是当时的真实伤害系列）我便问同学这是什么游戏，并在周末回家时马上下载玩了起来。Lolm也是因为我玩lol所以就玩了。现在说王者荣耀，又得说我那位亲近的朋友了，除了原神，王者荣耀也是他拉我入坑的，当时我七年级，他来我家玩用我手机下载的然后就开始玩了，甚至小学时洛克王国也是他带我入坑的。为什么刷抖音快手？因为抖音是17年很火吧，自然而然就下载长期刷了，快手则是13.14年比较火，这两个就不回溯了，无法避免。

那考研那年24年摆都干什么呢？其实和22年差不多，说点额外的，在24年8月26日，我从自习教室（5楼）下到3楼饮水机处接水，接完水就放窗台去吃晚饭了（拿着不方便就放窗台了），等我吃完饭回来 发现我的水杯水位变了，并且茶隔消失了。我心想这是有人要害我，我当时确实和一个同学关系很差，也许某些不认识我的人对我有敌意以及各种这样猜想，我有些无心学习了，马上就去校外的pcs查监控，但是晚上下班了，第二天上午又去，发现是有个神人，用的和我一模一样的水杯，但是他的没有茶隔，我的有。他接完水后把水杯放到窗台去上厕所了。出来以后没仔细看，把我的水杯拿走了

![1](/images/Picture4.png)



就是图中这哥们，说实在的我一直都对他怀恨在心。他不是故意的，只是粗心大意。但是对我的人生产生了无法估计的影响。我可以向内自己找自己的问题：不要疑神疑鬼，水杯不要了也不去看监控了时间紧迫赶快复习。但是如果不是他呢？我多学习了一晚上加一上午，我可能多获得了一些正反馈，慢慢一天一天我的自信心和复习水平指数复利，我会不会就不跳车了？我会不会就考上北大了？我这么想是因为我最后考研364分，北大录取最后一名351分，虽说不是一个专业课，我跳车后因为觉得好考10月11月都半学半玩，11月底才过完一遍专业课进入状态。也许不跳车考不上，二战也有希望，或者直接找工作呢？这些听着很扯，但是蝴蝶煽动翅膀导致龙卷风不也很扯吗?我们永远处于过去的余波中。这哥们完全就是天外来客，突然空降到我的人生。他和我素未谋面却改变了我的人生。另外就是我在考研开始的前一天2月25大概，突然联系了我原专业的一位朋友，我们在这之前聊天不怎么频繁的，他很早就开始考研了 我想着取取经。但从这以后，我们几乎天天聊天。他读过很多书，遣词造句都很有文学底蕴，有时候他会高姿态进行说教，而我不介意这个，我还给他当捧哏，另外他还挺逗的，我闲来无事就喜欢和他扯扯淡调侃他，这也成了我枯燥的考研生活的调味剂，但是缺点就是我们时长发消息发很久，或者就是高频的低密度信息，影响了彼此的专注。到后面我和他一个教室学习。有时候状态不好了就两人一起出去聊天，不学了。总的来说，最后我没考成北大，他也落榜了西交，互相耽误了属于。

# 曹丹的一天



由于长期垃圾饮食，最近一段时间尝试白天吃的健康一些，基本上中午都会去大米先生吃番茄炒蛋加杂粮饭，但是一到晚上6-7点，就感觉注意力涣散，我不清楚是我真的饿了，还是长期高热量饮食后突然低热量的身体反抗信号。今晚，我感觉胃口很大，就想着大吃一顿，恰逢科研毫无进展，仿真方面我以基本成为傀儡，实验也没法推进。老实说，做组里师哥师姐相似的课题蛮好的，有人带，而我觉得我就像开辟者，很累，最近往往也是差不多7点就回寝室了。



今天同样，接近7点半，我心想，吃牛new吧，正好上午体检抽了四管血，吃点牛肉补补铁。这种事情我很会找理由。



我健步如飞的走出园区，从2号线进入龙之梦，直奔电梯前往7楼牛new，电梯是镜面的，看着镜中的自己。。。以渐渐失去人形。



终于到了牛new.进去的时候八点多了，说是九点二十就不能点单了，九点半就打烊。所以我的食用时间就要从两小时削减到一小时半。

![进入牛new](/images/09162.JPG)



服务员高举左手带我来到了一个位置，“几位？”  “1位” 我秒答道。隔壁桌有一位粉头发女士，带着耳机，同样也是一位。看来我一人来吃也并不算稀奇。点了9盘肉后，等水开的时间我就去取鸭肠，拌料等东西了。



我是真饿了，狼吞虎咽猛吃了两盘鸭货，吃的很专注，根本听不到周围嘈杂的声音，好似也是一种心流。不一会，蘸料吃光了，我去再添加，猛然间，一个女生突然叫住了我，一头粉色头发，原来就是我隔壁的。看样子年龄和我差不多，她一边说，一边拿手机给我看。原来她都提前把字打好了，就是她多点了4盘肉，现在吃不上了，她没碰过，给我可不可以。我一下有点愣住了，第一次碰到这种事，甚至以前都没听过。我嗯了一会，想到我一会还会再点，女生看起来人畜无害，也答应了下来。就问她怎么操作，她说一会把肉放到我桌子上就可以。她笑着轻轻的和我道谢后就回到座位了，我在原地愣了一会。突然有点后悔答应下来了，想到万一她是极端恐怖分子或者极端恐怖女权随机陷害一位路人，里面下了毒药该怎么办？我第一想到的就是这个。



回到座位后，我和她面面相觑，她又不自然又尴尬的检查周围的服务员 有没有看着她，我这时才意识到，这是个偷偷摸摸的事，但是她表现得太明显了。就像小学幼儿园上课偷偷搞小动作的小孩，简直把自己的想法写到脸上了，而我就是她做这件不光明的事的同伙。我意识到事情不对劲，我明明是来吃自助餐的，我揽上这事干嘛。余光看到她欲动又止，我只得心里叹气，后悔了，不语，只低头吃着牛肉。一会一个戴眼镜服务员不知过来和她说了什么，我一抬头，这服务员走时脸上带着笑容，不是服务那种笑，仿佛是 看穿了什么，狡黠的笑容。



一会，终于她找到了机会，赶忙把4盘肉放到了我桌子上。笑着说了声谢谢，两手合并拜了拜🙏（就像这个emoji)我忘了我当时嘴里咕哝一句什么，反正她带着耳机也没听到（好像是索尼XM6）。这下她是完事了。到我了。



我先问了一下豆包：

![2](/images/09164.PNG)

看完心凉了，我忘了，有飞沫细菌病毒传播这档子事了 除了她是极端恐怖分子以外。那这肉是不能吃了。

可是我手快了，已经下到锅里了

![3](/images/09161.JPG)

就这样，我就只能吃自己点的肉捞出来的那点了。我还是没完全饱。只觉得操蛋揽上这件事。



我又去拿了很多水果，开始心里复盘了：

- 如果不是这位年轻漂亮的女士，而是一个男的。我会不会就没那么容易答应了？面对陌生人，该以什么原则对待？

  答案是没错。年轻美丽的女同志确实在社会工程学上有强大的实力，这让我发散想到，很多受到网络诈骗的人，很多都是以为自己很聪明不会被骗，其实是之前没碰到适合自己的骗局。所以，这档子破事怎么指导我以后的实践呢？

  

  那就是如果是陌生女士的请求，一定要严正的拒绝，不是因为我歧视仇视女性。是因为她们社会学工程能力太强了。比如一个人拿水枪和那一把军刀在我面前，我一定要小心拿军刀的，不是我仇视，歧视军刀，是因为它杀伤力太强了。所以以后，面对陌生，甚至不熟悉的女生的任何请求，完全拒绝

这样总结还是太片面。说个普适性的吧。**不理会任何陌生人，因为好事不会自己找上门**

真碰到了，以后我就假装韩国人，说两句韩语糊弄过去得了。如果有陌生人遇到困难我可以主动提供帮助，但是主动找我的一定装糊涂糊弄过去。这样有些绝对，二极管对吧？但是，就像今天，我是吃亏了才知道，以后吃自助，不要别人给的东西。但是这个结论价值太低了，我是亲自吃亏才上了这一课。这样所有的坑我都要亲自踩一次，才能学会。比如，也许很多人吃一辈子自助餐了，可能也不会有人要把自己吃不上的肉给他。所以经历的事情要能够得到普适性的启发才行。我觉得不理陌生人，足矣。



就在我大脑复盘的功夫。这位粉发女士依旧没走，我就纳闷了。都不吃了咋还不走，是不是要看我亲自吃下去才走.,我这么怀疑。过了大概20多分钟后终于走了。看着锅里，女生给的四盘肉 ，现在我又面临另外一给问题，就是 她的罚款可能要转移到我身上了。我的100押金，不保了

我想了几个方案，一是在打烊前，假装胃痛直接躺地上，服务员过来，我就艰难爬起来，把桌子上的食物装作痛苦，艰难的吃下去，带着他们可能会放我一马的希望。二就是打烊找我结算时，我就说这才一小时半，不是我浪费了，而是你们要打烊了，所以不怪我。第一个方案还是太激进和疯狂了，虽然我是老演员了，但是有点太拼了。



最后选择了方案二。出乎意料，到了九点半不是马上就赶人了，而是他们开始打扫卫生了，戴眼镜的那个服务员过来提醒我打烊了，带着一丝笑意，应该是她知道我和那女生的事，但是又让我慢慢吃完。过了一会，还是没人来催我，太难熬了。我站起来和茶，观察四周，还有零星几桌人在淡定的吃着。终于有个女服务员注意到我了

“先生，你吃完了吗？”

“还没，不过你们要下班了是吧？”

女服务员笑道：“嗯是的”

我面露难色“可是我还没吃完”，我希望她能让我别吃了，她们要下班打烊。

“啊那先生您先继续吃，我帮您把这些垃圾收走”

我意识到不对，赶快说“啊那你全收走吧，不耽误你们下班了”

女生笑了笑，就开始收拾了。我也帮他收拾了几个垃圾。心想无所谓了，这100就当交学费了。





出了牛new，我如释重负的叹了一口气，打开手机看看押金扣了多少，结果发现  原来20多分钟前，押金就全退给我了。。。我还在里面折腾那么久。这一天真是曹丹啊。
